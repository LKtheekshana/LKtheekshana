#### 🏛️ [Consultation DSS](https://github.com/LKtheekshana/consultation-dss)
LLM-based decision support system for citizen consultations (Information Center, Sri Lanka). A 7-stage pipeline: preprocessing → sentence embeddings (all-mpnet-base-v2) → retrieval → FLAN-T5 summarisation → Llama 3 generation → evaluation, plus a hallucinated-name fact-check and a Streamlit citizen/office portal.

`Python` `Transformers` `Llama 3` `Streamlit` `pytest`

</td>
<td width="50%" valign="top">

#### 👁️ [Diabetic Retinopathy Stage Detection](https://github.com/LKtheekshana/Diabetic-Retinopathy-Stage-Detection-with-Transfer-Learning)
Classifies retinal fundus images into 5 DR stages with EfficientNetB0 transfer learning on APTOS 2019. **QWK 0.853, ROC-AUC 0.90, 98% any-DR sensitivity**, with Grad-CAM explanations and a Streamlit prototype.

`TensorFlow` `Keras` `OpenCV` `Grad-CAM` `Streamlit`

</td>
